Exponent Rules

What Are Exponents?

An exponent tells you how many times to multiply a base by itself. In x3, the base is x and the exponent is 3, so x3 = x · x · x. Exponents are a shorthand that saves enormous amounts of writing in algebra, science, and finance.

The Core Rules

There are a handful of rules that let you simplify expressions with exponents without expanding everything out. Here are the ones you need:

RuleWhat It SaysWhy It Works
Product rulexm · xn = xm+nYou're just combining all the x's being multiplied
Quotient rulexm / xn = xm-nCancel the x's that appear in both top and bottom
Power rule(xm)n = xmnYou're raising a power to a power, so multiply them
Zero exponentx0 = 1Follows from the quotient rule: xn/xn = x0 = 1
Negative exponentx-n = 1/xnA negative exponent means "take the reciprocal"
✎ Worked Example — Product Rule
Simplify: x4 · x3
1Identify the rule: Both factors have the same base (x), so use the product rule.
2Add the exponents: 4 + 3 = 7
✓ Answer: x7
Common mistake: Students sometimes multiply the exponents (getting x12) instead of adding them. The multiplication rule only applies when a power is raised to another power, like (x4)3.
✎ Worked Example — Power Rule
Simplify: (x2)5
1Identify the rule: A power raised to a power — use the power rule.
2Multiply the exponents: 2 × 5 = 10
✓ Answer: x10
✎ Worked Example — Negative Exponent
Simplify and write with positive exponents: 3x-2
1Apply the rule: x-2 = 1/x2. The 3 out front is not affected.
2Rewrite: 3 · (1/x2) = 3/x2
✓ Answer: 3/x2
Common mistake: Writing the entire expression as 1/(3x2). Only the part with the negative exponent moves to the denominator — the coefficient 3 stays on top.
Any nonzero number raised to the 0 power is 1. So 50 = 1, (-3)0 = 1, and (1000)0 = 1. Real-world connection: if you save $1000 for 0 years, you still have $1000, multiplied by something0 = 1.

Factoring

What Is Factoring?

Factoring means rewriting an expression as a product of simpler pieces. It's like "un-distributing." If you know that 3 × 5 = 15, then factoring 15 gives you 3 × 5. In algebra we do the same thing with expressions involving x.

Always start by pulling out the GCF (greatest common factor) before trying anything else.

✎ Worked Example — Pulling out the GCF
Factor: 6x3 + 9x2
1Find the GCF: Both terms share a factor of 3 and at least x2. GCF = 3x2.
2Divide each term by 3x2: 6x3 ÷ 3x2 = 2x and 9x2 ÷ 3x2 = 3.
3Write the factored form: 3x2(2x + 3)
✓ Answer: 3x2(2x + 3)

Difference of Squares

This is the pattern you'll see most often. If you have something squared minus something else squared, it factors neatly:

a2 - b2 = (a + b)(a - b)

✎ Worked Example — Difference of Squares
Factor: x2 - 25
1Recognize the pattern: x2 is a perfect square, and 25 = 52. And the operation is subtraction, so this is a difference of squares.
2Apply the formula with a = x and b = 5: (x + 5)(x - 5)
3Verify by FOIL: (x + 5)(x - 5) = x2 - 5x + 5x - 25 = x2 - 25 ✓
✓ Answer: (x + 5)(x − 5)
Common mistake: Trying to factor x2 + 25 (a sum of squares). That does not factor over real numbers. The difference of squares pattern only works with subtraction.

Factoring Trinomials (x2 + bx + c)

When the leading coefficient is 1, you need two numbers that multiply to c and add to b.

✎ Worked Example — Factoring a Trinomial
Factor: x2 + 7x + 12
1Set up the goal: Find two numbers that multiply to 12 and add to 7.
2List factor pairs of 12: (1, 12), (2, 6), (3, 4)
3Check which pair adds to 7: 3 + 4 = 7. That's the one.
4Write the answer: (x + 3)(x + 4)
✓ Answer: (x + 3)(x + 4)
✎ Worked Example — Trinomial with Negative Signs
Factor: x2 - 2x - 15
1Set up the goal: Find two numbers that multiply to -15 and add to -2.
2Think about signs: Product is negative, so one number is positive and one is negative.
3Try pairs: -5 and +3 multiply to -15 and add to -2. ✓
4Write the answer: (x - 5)(x + 3)
✓ Answer: (x − 5)(x + 3)
Common mistake: Confusing which sign goes where. Always check your answer by FOILing it back out.

Solving Equations

Linear Equations

A linear equation has x to the first power (no x2 or higher). The goal is to get x by itself on one side. You do this by "undoing" what's been done to x using inverse operations: undo addition with subtraction, undo multiplication with division.

✎ Worked Example — Linear Equation
Solve: 3x + 7 = 22
1Undo addition first: Subtract 7 from both sides. → 3x = 15
2Undo multiplication: Divide both sides by 3. → x = 5
3Check your answer: 3(5) + 7 = 15 + 7 = 22 ✓
✓ Answer: x = 5
Common mistake: Dividing before subtracting. Always clear addition/subtraction before multiplication/division — work from the outside in.

Quadratic Equations

A quadratic has x2 as its highest power. Standard form is ax2 + bx + c = 0. There are several ways to solve these:

Method 1: Factoring. If the expression factors, set each factor equal to zero.

Method 2: Quadratic formula. This always works:

x = (-b ± √(b2 - 4ac)) / 2a

✎ Worked Example — Solving by Factoring
Solve: x2 - 5x + 6 = 0
1Find the right pair: Multiply to 6 and add to -5. That's -2 and -3.
2Factor: (x - 2)(x - 3) = 0
3Zero Product Property: If a product is zero, at least one factor must be zero.
4x - 2 = 0 → x = 2   |   x - 3 = 0 → x = 3
✓ Solutions: x = 2 and x = 3
✎ Worked Example — Quadratic Formula
Solve: 2x2 + 3x - 5 = 0
1Identify a, b, c: a = 2, b = 3, c = -5
2Compute the discriminant: b2 - 4ac = 9 - 4(2)(-5) = 9 + 40 = 49
3Take the square root: √49 = 7
4Apply the formula: x = (-3 ± 7) / (2 · 2) = (-3 ± 7) / 4
5x = (-3 + 7)/4 = 4/4 = 1   |   x = (-3 - 7)/4 = -10/4 = -5/2
✓ Solutions: x = 1 and x = −5/2
Common mistake: Forgetting the ± symbol, which gives you only one solution instead of two. Also, a very common error is computing 2a as just "a" — remember to multiply 2 times the entire value of a.

The Discriminant: How Many Solutions?

The expression under the square root in the quadratic formula, b2 - 4ac, is called the discriminant. It tells you what kind of solutions you'll get before you even solve:

If b2 - 4ac is...Then you get...
PositiveTwo different real solutions
ZeroExactly one real solution (a "double root")
NegativeNo real solutions
A negative discriminant means you'd be taking the square root of a negative number, which has no answer in the real number system. Think of it graphically: the parabola never crosses the x-axis.

Absolute Value Equations

The absolute value of a number is its distance from zero, so it's always positive or zero. To solve |expression| = k, you write two equations: expression = k, and expression = -k.

✎ Worked Example — Absolute Value Equation
Solve: |x - 3| = 7
1Think about it: "The distance between x and 3 is 7." Two points on a number line are 7 away from 3.
2Write two equations: x - 3 = 7 and x - 3 = -7
3Solve each: x = 10 and x = -4
4Check: |10 - 3| = |7| = 7 ✓ and |-4 - 3| = |-7| = 7 ✓
✓ Solutions: x = 10 and x = −4

Inequalities

The One Big Rule

You solve inequalities almost exactly like equations, with one critical exception: when you multiply or divide both sides by a negative number, you must flip the inequality sign.

✎ Worked Example — Linear Inequality
Solve and express in interval notation: -2x + 5 > 11
1Subtract 5 from both sides: -2x > 6
2Divide by -2 AND flip the sign (dividing by negative): x < -3
3Express in interval notation: (-∞, -3)
✓ Answer: x < -3, or (-∞, -3)
Most common error in algebra: Forgetting to flip the inequality sign when dividing by a negative. If you forget, your answer is exactly backwards.

Interval Notation

Interval notation is a compact way to write the solution set. Parentheses mean "not included" (open circle on a number line), brackets mean "included" (closed circle). Infinity always gets a parenthesis because you can never reach it.

MeaningNotation
x is between 2 and 7, not including endpoints(2, 7)
x is between 2 and 7, including both[2, 7]
x is greater than 5(5, ∞)
x is less than or equal to 3(-∞, 3]

Absolute Value Inequalities

These follow a simple pattern. Think of absolute value as distance from zero:

|x| < a means x is between -a and a: -a < x < a

|x| > a means x is outside that range: x < -a or x > a

✎ Worked Example — Absolute Value Inequality
Solve: |2x + 1| < 5
1"Less than" means between (compound inequality): -5 < 2x + 1 < 5
2Subtract 1 from all three parts: -6 < 2x < 4
3Divide all parts by 2: -3 < x < 2
4Interval notation: (-3, 2)
✓ Answer: -3 < x < 2, or (-3, 2)
Memory trick: "Less thAND" (the solution is one interval joined by AND). "GreatOR" (two separate pieces joined by OR).

Functions

What Is a Function?

A function is a rule that takes each input (x) and produces exactly one output (y). Think of it as a vending machine: you press B4 and one specific item comes out. If pressing B4 might give you a Snickers or a bag of chips depending on the day — that's not a function.

Vertical Line Test: If you can draw a vertical line anywhere on a graph and it hits the curve more than once, the graph is not a function.

Notation: f(x) means "the output of function f when the input is x." It is NOT f times x.

Evaluating a Function

To evaluate f(a), replace every x in the formula with a. This is just substitution — treat x like a blank, fill in the value.

✎ Worked Example — Evaluating a Function
If f(x) = 2x2 - 3x + 1, find f(4).
1Replace every x with 4: f(4) = 2(4)2 - 3(4) + 1
2Evaluate 42 first: = 2(16) - 12 + 1
3Multiply: = 32 - 12 + 1
4Add/subtract left to right: = 21
✓ f(4) = 21
Common mistake: Writing f(4) = 2x2 - 3(4) + 1 but forgetting to substitute for the x inside x2. Substitute everywhere.

Domain: What Can You Plug In?

The domain is the set of all x-values you're allowed to use. Most of the time, the domain is all real numbers. But there are three situations that create restrictions:

1. Fractions: The denominator cannot be zero. Find what makes it zero and exclude that.

2. Square roots (even roots): The expression under the root must be ≥ 0.

3. Logarithms: The argument must be > 0.

✎ Worked Example — Domain with a Square Root
Find the domain of f(x) = √(x - 3)
1Square roots need non-negative input: set the radicand ≥ 0: x - 3 ≥ 0
2Solve the inequality: x ≥ 3
3Write in interval notation: [3, ∞)
✓ Domain: [3, ∞)
✎ Worked Example — Domain with a Fraction
Find the domain of g(x) = 1/(x2 - 9)
1Denominator cannot be zero: x2 - 9 ≠ 0
2Factor and solve: (x + 3)(x - 3) = 0 gives x = 3 and x = -3
3Exclude those values: all reals except x = 3 and x = -3
✓ Domain: all real numbers except x = 3 and x = −3

Graph Transformations

How Graphs Move

Once you know the shape of a basic graph (like x2 or √x), you can shift, stretch, or flip it using simple rules. Starting from a graph y = f(x):

ChangeEffect on the Graph
f(x) + kShift up k units
f(x) - kShift down k units
f(x - h)Shift right h units
f(x + h)Shift left h units
-f(x)Flip over the x-axis
f(-x)Flip over the y-axis
✎ Worked Example — Describing a Transformation
Describe the graph of y = (x - 2)2 + 5
1Start with the parent function y = x2 (a U-shaped parabola at the origin).
2(x - 2) inside means horizontal shift. Opposite of the sign: shift right 2.
3+ 5 outside means vertical shift: shift up 5.
4Result: a parabola with vertex at (2, 5), opening upward.
✓ Vertex at (2, 5), opens upward — same shape as y = x2, just moved.
Common mistake: Horizontal shifts feel backwards. f(x - 3) shifts RIGHT (not left), and f(x + 3) shifts LEFT (not right). Always think "opposite of the sign inside."

Inverse Functions

What Is an Inverse?

An inverse function undoes what the original function does. If f turns 2 into 7, then f-1 turns 7 back into 2. Think of it like directions: if f is the steps to get from your dorm to the library, f-1 is the reverse walk back.

The notation f-1 does NOT mean 1/f(x). It means the inverse function.

A function can only have an inverse if it's one-to-one, meaning each y-value comes from only one x-value. You check this with the Horizontal Line Test: if any horizontal line crosses the graph more than once, it fails.

How to Find an Inverse

Three steps: (1) replace f(x) with y, (2) swap x and y, (3) solve for y.

✎ Worked Example — Finding an Inverse
Find the inverse of f(x) = 3x - 5
1Replace f(x) with y: y = 3x - 5
2Swap x and y (this is the key step): x = 3y - 5
3Solve for y: x + 5 = 3y → y = (x + 5)/3
4Write using inverse notation: f-1(x) = (x + 5)/3
✓ f-1(x) = (x + 5)/3
The graphs of f and f-1 are mirror images across the line y = x. Also, verify your answer by checking that f(f-1(x)) = x.

Quadratic Functions & Parabolas

The Vertex: The Most Important Point

Every parabola y = ax2 + bx + c has a highest or lowest point called the vertex. In real life, this is the peak of a ball's arc, or the minimum cost in a business model. You find it with this formula:

x = -b / (2a), then plug that x back in to find y.

If a > 0, the parabola opens up (the vertex is a minimum). If a < 0, it opens down (the vertex is a maximum).

✎ Worked Example — Finding the Vertex
Find the vertex of f(x) = -2x2 + 8x - 3 and determine if it is a maximum or minimum.
1Identify a, b: a = -2, b = 8
2Find the x-coordinate: x = -b/(2a) = -8 / (2 · -2) = -8 / -4 = 2
3Find the y-coordinate: f(2) = -2(4) + 8(2) - 3 = -8 + 16 - 3 = 5
4Check direction: a = -2 < 0, so the parabola opens down → the vertex is a maximum.
✓ Vertex: (2, 5). This is a maximum because a < 0.

Polynomial Basics

End Behavior

The end behavior of a polynomial is what happens to the graph as x goes very far left or very far right. It depends on two things: the degree (highest exponent) and the leading coefficient (the number in front of the highest power).

DegreeLeading Coeff.Left EndRight End
EvenPositiveUpUp
EvenNegativeDownDown
OddPositiveDownUp
OddNegativeUpDown
Even degree = both ends go the same way (like x2 — both ends up). Odd degree = ends go opposite ways (like x3 — one up, one down).

Zeros and Multiplicity

When a factor like (x - 2) appears in a polynomial, x = 2 is a zero (the graph hits the x-axis there). The multiplicity is how many times that factor repeats:

Odd multiplicity (1, 3, 5...): the graph crosses the x-axis at that zero.

Even multiplicity (2, 4, 6...): the graph touches and bounces off the x-axis.

✎ Worked Example — Zeros and Multiplicity
Describe the behavior at each zero of f(x) = (x + 1)2(x - 3)
1Identify the zeros: x = -1 (from (x+1)2) and x = 3 (from (x-3))
2x = -1: appears with multiplicity 2 (even) → graph bounces off the x-axis here.
3x = 3: appears with multiplicity 1 (odd) → graph crosses through the x-axis here.
✓ Bounces at x = −1; crosses at x = 3

Rational Functions

Asymptotes: Lines the Graph Approaches But Never Reaches

A rational function is a fraction where the top and bottom are both polynomials: f(x) = p(x)/q(x).

Vertical asymptote (VA): Set the denominator equal to zero and solve. The graph shoots toward ±∞ near these x-values.

Horizontal asymptote (HA): Compare the degree of the numerator (top) to the degree of the denominator (bottom):

If...Then the HA is...
Degree of top < degree of bottomy = 0
Degree of top = degree of bottomy = (leading coeff. of top) / (leading coeff. of bottom)
Degree of top > degree of bottomNo horizontal asymptote
✎ Worked Example — Finding Asymptotes
Find all asymptotes of f(x) = (3x + 1) / (x - 4)
1Vertical asymptote: Set denominator = 0. x - 4 = 0 → VA at x = 4
2Horizontal asymptote: Degree of top = 1, degree of bottom = 1 (equal).
3HA = ratio of leading coefficients: 3/1 = 3 → HA at y = 3
✓ Vertical asymptote: x = 4. Horizontal asymptote: y = 3.
Common mistake: Confusing the VA and the HA. The VA is a vertical line (an x-value the function can't touch). The HA is a horizontal line (what the function approaches far left and right).

Exponentials & Logarithms

Exponential Functions

An exponential function has the variable in the exponent: f(x) = bx, where b > 0 and b ≠ 1. The graph always passes through (0, 1) because anything to the zero power is 1.

If b > 1, the function grows (gets bigger fast). If 0 < b < 1, the function decays (shrinks toward zero). Populations, compound interest, and viral spread are all exponential growth. Radioactive decay and drug elimination from the body are exponential decay.

The special base e ≈ 2.71828 shows up constantly in science and finance because it makes calculus much simpler.

What Is a Logarithm?

A logarithm answers the question: "What exponent do I need?"

logb(x) = y means by = x

In plain English: "log base b of x" asks, "what power do I raise b to in order to get x?"

✎ Worked Example — Evaluating a Logarithm
Evaluate: log2(32)
1Ask the question: "2 raised to what power gives 32?"
2Think through powers of 2: 21=2, 22=4, 23=8, 24=16, 25=32
3Answer: 25 = 32, so the exponent is 5.
✓ log2(32) = 5

Two key facts: logb(1) = 0 (because b0 = 1) and logb(b) = 1 (because b1 = b).

Log Properties

Logarithms have three properties that let you break apart or combine expressions. These mirror the exponent rules:

PropertyFormulaWhat It Does
Product rulelog(MN) = log(M) + log(N)Turns multiplication into addition
Quotient rulelog(M/N) = log(M) - log(N)Turns division into subtraction
Power rulelog(Mp) = p · log(M)Brings the exponent down as a multiplier

Solving Exponential Equations

When the variable is in the exponent and you can't match bases, take the log of both sides and use the power rule to bring the exponent down.

✎ Worked Example — Solving an Exponential Equation
Solve: 5x = 200
1Can we match bases? 200 is not a power of 5, so use logarithms.
2Take ln of both sides: ln(5x) = ln(200)
3Power rule brings x down: x · ln(5) = ln(200)
4Divide both sides by ln(5): x = ln(200) / ln(5) ≈ 5.298 / 1.609 ≈ 3.29
✓ x = ln(200) / ln(5) ≈ 3.29
Common mistake: Writing x = ln(200/5) = ln(40). That is NOT the same as ln(200)/ln(5). Log division properties don't work that way.

Compound Interest

Two formulas to know:

Compounded n times per year: A = P(1 + r/n)nt

Compounded continuously: A = Pert

Where A = final amount, P = principal (starting amount), r = annual rate as a decimal, n = times compounded per year, t = years.

✎ Worked Example — Continuous Compound Interest
$5,000 is invested at 4% annual interest, compounded continuously. How much will be in the account after 10 years?
1Identify the values: P = 5000, r = 0.04 (4% as a decimal), t = 10
2Write the formula: A = Pert = 5000 · e(0.04)(10)
3Simplify the exponent: 0.04 × 10 = 0.4
4Calculate: A = 5000 · e0.4 ≈ 5000 · 1.4918 ≈ $7,459.12
✓ The account will have approximately $7,459.12 after 10 years.
Common mistake: Using r = 4 instead of r = 0.04. Always convert a percent to a decimal by dividing by 100 before plugging it in.
